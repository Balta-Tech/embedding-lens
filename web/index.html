What does a video embedding see?

Six videos, cut into five-second moments. Each moment becomes a single vector in a space it shares with language, and we ask which words land closest.

How it works

  1. 1

    Cut

    291 moments of 5 seconds, sampled at two frames per second.

  2. 2

    Embed

    A model turns each moment into one vector, in the same space it maps sentences to.

  3. 3

    Read out

    Rank up to 119,000 words and phrases by closeness, and check the result against the frames.

    Live features

    Everything on this page works from precomputed results. Free-text search and scoring words outside the built-in vocabulary need the embedding models, served from embedded-lens-api.balta-tech.com. When that is offline, run the backend yourself:

    git clone https://github.com/Balta-Tech/embedding-lens
cd embedding-lens && uv sync
uv run uvicorn lens.api:app --port 8000

    Then point this page at it from the browser console: localStorage.setItem("embedding-lens:api", "http://localhost:8000") and reload.
